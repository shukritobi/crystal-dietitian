# Crystal Dietitian

A mobile-first concept website for **Crystal Dietitian**.

## Purpose

The site upgrades a basic link-in-bio page into a professional personal-brand website with:

- Registered dietitian positioning
- Product recommendation cards
- Nutrition education content
- Instagram conversion paths
- Affiliate and educational disclaimers
- Responsive mobile design
- GitHub Pages deployment workflow

## Preview

Once GitHub Pages is enabled with **GitHub Actions** as the source:

`https://shukritobi.github.io/crystal-dietitian/`

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Before production launch

Replace or confirm:

- Product destination URLs
- Product imagery and approved descriptions
- Consultation / collaboration contact method
- Privacy policy and commercial disclosures
- Crystal's approval to use her portrait and credential
